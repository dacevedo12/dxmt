# DXMT

> **This repository is archived.** It is my fork of DXMT, where I built a
> Direct3D 9 frontend on top of DXMT's Metal backend. That codebase turned out
> to be a dead end, with no realistic chance of being merged upstream. I have
> since moved to contributing to [athei/mtld3d](https://github.com/athei/mtld3d),
> a Direct3D 9 implementation on Metal that is a far cleaner and more performant
> layer. For DXMT itself, see [3Shain/dxmt](https://github.com/3Shain/dxmt).

A Metal-based translation layer for Direct3D 11, 10 and 9 which allows running 3D applications on macOS using Wine.

For the current status of the project, please refer to the [project wiki](https://github.com/3Shain/dxmt/wiki).

The most recent development builds can be found [here](https://github.com/3Shain/dxmt/actions).
